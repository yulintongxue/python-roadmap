# python-roadmap

从零开始的 Python 学习仓库。每天一个文件夹，每天一个 commit。

## 目录

| 文件夹 | 内容 |
|---|---|
| `day01/` | 环境、hello world、Git 首次提交 |
| `day02/` | 类型、分支：BMI、闰年 |
| `day03/` | 循环：猜数字、九九乘法表 |
| `day04/` | 列表与字典：命令行待办 |
| `day05/` | 函数：把待办拆成函数 |
| `day06/` | 文件与异常：JSON 持久化 |
| `day09/` | 十种常见报错 |
| `todo/` | 待办工具（逐步升级：内存 → JSON → SQLite → CLI） |
| `todo_api/` | FastAPI 后端项目（第 4 周） |

## 怎么运行

```bash
python day01/hello.py
```
